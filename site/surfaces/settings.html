Settings

A static recreation of the extension's Settings page — where you set the ServiceNow instance, the queues and team members every pull is scoped to, pull parameters, classification behaviour, the MSR option lists and classifier keywords, and backup/transfer. In the real extension these values live in chrome.storage.local and the chips are injected by JavaScript. Everything below is a sample and inert. Hover or focus a card on the right for a guided tour, or read the Configuration and Classification docs.

Classification

How the MSR Root cause and Solution type columns are filled from the resolution notes. The built-in offline scorer always runs; the machine-learning model (downloaded once and cached locally, used offline in the Data View) is only used when the mode asks for it.
Choose which classifier to download. Larger models are more accurate but take longer to download.

Stores each classified note's outcome in a local cache, so an unchanged note is never re-inferred on reload or across datasets. Turn off to always re-classify. This only affects future runs; existing rows are already classified.

Classifier keywords

Word and phrase hints the built-in offline scorer uses to match MSR labels while classifying the resolution notes (regex phrase, keyword hints, then vocabulary similarity). Each label shows its built-in default keywords; add chips to extend them, or clear them to remove a match. Matching is case-insensitive and tolerates small misspellings. Editing a label's keywords re-runs classification in the data view and bumps the keyword fingerprint.

Backup / transfer

Exports one JSON file with instance URL, queues, team members, pull params, saved filters, column mapping, CI split groups, hidden view columns, MSR option lists and the cached Excel template. Import replaces all of those with the file's values.
