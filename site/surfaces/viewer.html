Data Viewer

The Data Viewer is where you inspect, search, edit, classify, and export a pulled ServiceNow dataset. It reads its rows from the extension's local storage, shows the pulled tickets plus derived timeline columns (assign, acknowledge, suspend, resume and the durations derived from them), and lets you refine them before they land in the exported report. Times follow the instance clock, not your browser.

Below is a faithful, static recreation of the viewer with a realistic sample dataset, scaled to fit. Every control is explained on the right — hover or focus a card and the arrow points to that control. Nothing here is live.

Export column mapping

Pick the Excel column (A–AN) each field is written to. A field exports to one column; unmapped fields are skipped and unmapped columns stay as the template has them.

Split export by configuration item

Groups become the file names. Drag configuration items between groups. An item matches every configuration item that contains it (anywhere in the name) — e.g. "Payment Gateway" also matches "Payment Gateway PRD / PreLive / DEV / TEST" and "Web Payment Gateway". Longest match wins; the rest go to Others. Add one item per box, or paste/type several separated by commas or new lines.
