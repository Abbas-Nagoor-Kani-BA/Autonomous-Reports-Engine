The Autonomous Reports Engine, explained screen by screen.

A Chrome (Manifest V3) side-panel extension that pulls ServiceNow ticket timelines, analyzes SLA performance, classifies resolution notes, and exports a filled Excel report — running entirely offline and reusing your existing logged-in ServiceNow session, so it needs no API keys. This site recreates each interface with annotated callouts and hosts the full documentation.

What it does

A pull reuses your open ServiceNow tab's session, reconstructs each ticket's timeline and SLA metrics, classifies the closure notes, and writes the results to local storage — which the Data Viewer reads for search, editing, and export.

Key features

Everything the extension does, at a glance.

  • Session-based pull Reads incident / RFS / problem / task tickets through your logged-in ServiceNow tab. No credentials stored, no API keys.
  • Queue timelines & SLA Reconstructs assign, acknowledge, suspend and resume moments from audit history and derives SLA metrics on the instance clock.
  • Automatic classification Fills root-cause category and solution type from closure notes with an offline scorer, plus an optional local ML model.
  • Data viewer Column-scoped search, a fast single-column bulk editor, CI split preview, ticket stats, and Calclens explanations.
  • Excel export Fills a template workbook and offers Copy for MSR for pasting into an existing sheet.
  • Offline & private Pulled data and settings stay local; the ML model runs entirely offline after a one-time download.
